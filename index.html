Module 2 • Grammar & Practice

Comparing Two Places (Comparatives)

Use comparative adjectives + than to contrast two cities, countries, or travel styles.

Golden Formula

Place A + is/are + [Comparative] + than + Place B

1. Short (1 Syllable)

Adjective + -er

cheap → cheaper
clean → cleaner
big → bigger (CVC double)

2. Ending in -y

Change -y to -ier

busy → busier
noisy → noisier
friendly → friendlier

3. Long (2+ Syllables)

more + Adjective

crowded → more crowded
expensive → more expensive
peaceful → more peaceful

4. Irregulars

Special Forms

good → better
bad → worse
far → farther / further

Module 3 • Ranking & Extremes

The Ultimate Destination (Superlatives)

Use superlative adjectives with "the" to compare three or more places and highlight #1 extremes.

Golden Rule

Always use the + [Superlative] (e.g., the biggest)

1. Short (1 Syllable)

the + adj + -est

big → the biggest
cheap → the cheapest
old → the oldest

2. Ending in -y

the + adj (-iest)

busy → the busiest
pretty → the prettiest
friendly → the friendliest

3. Long (2+ Syllables)

the most + Adjective

famous → the most famous
exciting → the most exciting
modern → the most modern

4. Irregulars

Special Forms

good → the best
bad → the worst
far → the farthest / furthest
